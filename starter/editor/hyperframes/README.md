# Hyperframes motion layer

Hyperframes is included as part of this editor kit, not as an optional afterthought.

Recommended flow:

1. Design a deterministic HTML scene or motion block.
2. Validate it: `npm run hyperframes:lint && npm run hyperframes:validate`.
3. Preview it locally.
4. Use it as a Remotion overlay, full-screen explainer, PNG/video sequence, or reference scene.

Keep public examples generic. Do not ship private client assets, local paths, or internal production scripts.
