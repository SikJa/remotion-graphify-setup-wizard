# Hyperframes integration

Hyperframes is part of the full editor install.

Use it for:

- motion cards;
- animated diagrams;
- explainer overlays;
- arrows and process maps;
- HTML scenes that can be validated, previewed and imported into Remotion.

The generated workspace includes:

- `hyperframes/README.md`
- `hyperframes/motion-card.html`
- `src/hyperframes/HyperframeMotionCard.tsx`
- `npm run hyperframes:lint`
- `npm run hyperframes:validate`

Keep examples public-safe and generic.
