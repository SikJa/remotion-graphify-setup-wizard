# Editor Kit included in the wizard

The wizard now installs a real editor workspace, not only folders.

Included by default:

- 25+ Remotion components for text, captions, overlays, media, backgrounds and layout.
- Real templates for TikTok, Instagram Reel, YouTube Short, presentation, testimonial, announcement, before/after, talking head and podcast clips.
- Pipeline scripts for video analysis, audio extraction, transcription, silence detection, background removal and batch rendering.
- Agent rules and a reusable skill pack.
- Graphify integration for codebase understanding.
- Hyperframes motion layer for HTML/motion-graphic scenes.

This public kit is based on the internal Editor Pro Max system and adapted into a clean, generic installable starter.
